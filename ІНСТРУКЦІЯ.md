# Інструкція: Attack Shark Battery

Програма показує заряд мишки Attack Shark цифрами біля годинника Windows. Підтверджено на **X11**
(2.4G-ресивер). Права адміністратора не потрібні.

---

## 1. Встановлення (для звичайного користувача)

1. Відкрийте сторінку **Releases** репозиторію:
   https://github.com/Krebeke/attack-shark-battery/releases
2. В останньому релізі завантажте `AttackSharkBattery-Setup.exe`.
3. Запустіть його. Якщо Windows покаже «Windows захистив ваш ПК», натисніть
   **«Докладніше» → «Виконати в будь-якому разі»**. Програма не підписана сертифікатом, тому таке
   попередження нормальне.
4. Залиште галочку «Запускати разом із Windows», якщо хочете, щоб програма стартувала сама.
5. Після встановлення біля годинника з'явиться значок із цифрами заряду. Якщо його не видно,
   натисніть стрілку **^** біля годинника й перетягніть значок на панель.

Видалити: **Параметри → Програми → Attack Shark Battery → Видалити**.

---

## 2. Користування

### Значок у треї
- **Цифри**: поточний заряд у відсотках.
- **Наведіть мишу**: підказка, наприклад «Attack Shark X11: 57%».
- **Лівий клік**: головне вікно.
- **Правий клік**: меню (Оновити зараз, Налаштування, Міні-віджет, Автозапуск, Вихід).

| Що бачите | Що це означає |
|---|---|
| Число (57) | Заряд мишки |
| Сіре число | Мишка спить, показано останній відомий заряд |
| `--` | Мишку не знайдено: вимкнена або ресивер не вставлений |
| `!` | Помилка в `config.json` |

### Головне вікно
Велика цифра заряду, статус зарядки, приблизний час до розряду, графік за 24 год / 7 / 30 днів
і кнопка **«Експорт CSV…»**, щоб зберегти історію для Excel.

### Міні-віджет
Увімкнути можна через меню значка → «Міні-віджет» або в Налаштуваннях → «Віджет».
- **Перетягуйте** мишею. Біля краю екрана віджет прилипає до нього.
- **Колесо миші** над віджетом змінює розмір.
- **Подвійний клік** відкриває головне вікно, **правий клік** відкриває меню.
- **Положення**: «Поверх усіх вікон» або «Прикріплений до робочого столу» (лежить під вікнами, як гаджет).
- **Розмір**: лише цифри / цифри + шкала / з міні-графіком.
- **Прозорість**, ховання в повноекранних іграх, червона рамка при низькому заряді.
- **«Клікати крізь віджет»**: віджет перестає реагувати на мишу. Вимкнути цей режим можна
  тільки в меню значка в треї → «Віджет: пропускати кліки».

### Сповіщення
- Заряд нижче порога (за замовчуванням 15%) і повторне нагадування кожні 30 хв.
- «Заряд 100%», коли мишка зарядилась.

### Кілька мишок
Налаштування → вкладка **«Мишки»**:
- **«Додати знайдену»** додає підключену мишку відомої моделі.
- **«Додати нову (навчання)…»** відкриває майстер для іншої мишки (див. розділ 3).
- **«Перейменувати…»** і **«Видалити»** змінюють вибрану мишку.

Значок у треї показує мишку з **найменшим** зарядом, підказка перелічує всі. У головному вікні
нагорі з'являється перемикач мишок.

## 3. Якщо мишку не знайдено

1. Переконайтесь, що мишка **ввімкнена** і ресивер вставлений. Рухніть мишкою й натисніть
   правою кнопкою на значок → «Оновити зараз».
2. Налаштування → «Мишки» → **«Знайти мишку…»**:
   - **Відомі моделі**: якщо мишка є у списку, оберіть її й натисніть «Використати вибрану».
   - **Навчання**: відкрийте офіційну програму Attack Shark, подивіться, який заряд вона показує,
     введіть це число, оберіть ресивер і натисніть «Почати». 12 секунд не рухайте мишку.
     Потім оберіть перший варіант і натисніть «Застосувати».
   - **Статус зарядки**: натисніть «Записати БЕЗ зарядки», поставте мишку на зарядку,
     зачекайте 3 с і натисніть «Записати НА зарядці».
3. Якщо навчання нічого не знайшло, ця модель віддає заряд лише у відповідь на запит. Тоді потрібен
   запис трафіку через USBPcap + Wireshark. Створіть Issue на GitHub і прикріпіть файл `.pcapng`.

## 4. Оновлення

Програма раз на добу сама перевіряє GitHub. Коли виходить нова версія:
1. З'являється сповіщення, а в меню значка пункт **«Оновити до X.Y.Z…»**.
2. Натисніть його і підтвердіть. Інсталятор завантажиться, перевіриться й встановиться сам,
   а програма перезапуститься. Налаштування й історія зберігаються.

Перевірити вручну: Налаштування → «Робота» → «Оновлення» → **«Перевірити зараз»**.
Вимкнути: прибрати галочку «Перевіряти нові версії на GitHub».

Версія 1.0.0 оновлень не вміє, тому з неї треба один раз поставити новий Setup.exe вручну.

---

## 5. Де зберігаються дані

Папка `%APPDATA%\AttackSharkBattery\` (вставте цей шлях в адресний рядок Провідника):
- `config.json`: усі налаштування;
- `history.csv`: історія заряду за 30 днів;
- `battery.log`: журнал (знадобиться, якщо щось не працює).

Щоб скинути налаштування, закрийте програму (значок → «Вихід») і видаліть `config.json`.
Під час видалення програми ці дані лишаються.

## 6. Часті проблеми

| Проблема | Рішення |
|---|---|
| «Програма вже запущена» | Значок уже є біля годинника, можливо за стрілкою **^** |
| Завжди `--` | Мишка вимкнена або інша модель. Див. розділ 3 |
| Значок сірий | Мишка заснула. Рухніть нею, і за кілька секунд з'явиться заряд |
| Статус зарядки «невідомий» | Його не навчено. Див. розділ 3, пункт «Статус зарядки» |
| Під час зарядки кабелем `--` | Мишка перейшла в дротовий режим, ресивер мовчить. Це нормально |
| Не видно віджет | Увімкнений режим «на робочому столі», тож віджет під вікнами. Згорніть вікна (Win+D) |
| Віджет не реагує на мишу | Увімкнено «кліки крізь віджет». Вимкніть у меню значка |
| Сповіщення не з'являються | Параметри Windows → Система → Сповіщення: увімкніть їх і вимкніть «Не турбувати» |
| Захист Windows блокує Setup.exe | «Докладніше» → «Виконати в будь-якому разі» |

Якщо проблема лишилась, створіть **Issue** на GitHub, опишіть її та прикріпіть `battery.log`.

## 7. Як передати другу

Надішліть посилання на сторінку Releases (розділ 1) або сам файл `AttackSharkBattery-Setup.exe`.
Більше нічого не потрібно: Python і бібліотеки вже всередині інсталятора.

---

## 8. Для розробника: збірка й випуск нової версії

### Перший раз
1. Встановіть **Python 3** (з галочкою «Add python.exe to PATH») і **Inno Setup 6**
   (https://jrsoftware.org/isdl.php). Visual Studio не потрібна.
2. Завантажте код: зелена кнопка **Code → Download ZIP** і розпакуйте, або `git clone`.

### Запуск із коду (для перевірки)
```
cd шлях\до\папки
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python tray_battery.py
```

### Збірка інсталятора
Запустіть `build.bat`. Результат: `installer_output\AttackSharkBattery-Setup.exe`.

Якщо з'являється помилка **«EndUpdateResource failed… antivirus»**, запустіть `build.bat` ще раз
або додайте папку проєкту у виключення Windows Defender («Безпека Windows» → «Захист від вірусів
і загроз» → «Керування параметрами» → «Виключення»).

### Випуск нової версії
1. У `version.py` збільште номер, наприклад `VERSION = "1.2.2"`.
2. Запустіть `build.bat`.
3. На GitHub: **Releases → Draft a new release**.
   - **Choose a tag**: введіть `v1.2.2` (з літерою `v`, той самий номер) → «Create new tag on publish».
   - Заголовок і короткий опис змін.
   - Перетягніть `installer_output\AttackSharkBattery-Setup.exe` у поле для файлів.
   - **Publish release**.
4. Протягом доби всі встановлені копії запропонують оновитися.

Назва файлу має закінчуватися на `Setup.exe`, а реліз не повинен бути чернеткою чи pre-release.
Інакше програма його не побачить.

### Файли проєкту
| Файл | Що робить |
|---|---|
| `tray_battery.py` | Головний файл: значок, меню, сповіщення |
| `service.py` | Фонове опитування мишок |
| `hidreader.py` | Читання заряду з HID, робота з `config.json` |
| `detect.py` | Відомі моделі, навчання, автопошук |
| `ui.py` | Усі вікна і віджет |
| `history.py` | Історія заряду, CSV |
| `updater.py`, `version.py` | Автооновлення, номер версії |
| `iconrender.py`, `theme.py`, `i18n.py`, `winutil.py`, `uimanager.py` | Іконка, тема, переклади, функції Windows |
| `find_device.py` | Консольна утиліта: список HID-пристроїв, перевірка читання |
| `build.bat`, `installer.iss` | Збірка .exe та інсталятора |

Технічні подробиці (ключі `config.json`, протокол X11) є в [README.md](README.md) (англійською).
